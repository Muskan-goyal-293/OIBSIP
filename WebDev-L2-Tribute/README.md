# 🇮🇳 Dr. A.P.J. Abdul Kalam | Advanced Tribute & Legacy Portal

A visually engaging and fully responsive tribute website dedicated to **Dr. A.P.J. Abdul Kalam** — India's Missile Man, renowned aerospace scientist, and the 11th President of India.

This project was developed using **HTML5 & CSS3** as part of the **Oasis Infobyte Web Development & Designing Internship (Level 2 – Tribute Page)**.

## ✨ Features

- 🇮🇳 Elegant tribute page dedicated to Dr. A.P.J. Abdul Kalam
- 🖼️ Prominent hero image with professional introduction
- 📖 Original biography with 3+ detailed tribute sections
- 🕒 Timeline of major life milestones
- 🏅 Achievement cards with images and descriptions
- 📚 Top 8 literary works section
- 💬 Inspirational quotes section
- 🎤 Motivational speeches section
- 🎨 Glassmorphism + Indian tricolour themed UI
- 🔗 Smooth scrolling navigation
- 📱 Fully responsive (Desktop, Tablet & Mobile)
