# To-Do Web App

## Overview

A responsive and user-friendly To-Do Web Application built using HTML, CSS, and JavaScript. This project helps users organize daily tasks efficiently by allowing them to add, edit, complete, and delete tasks. All task data is stored in Local Storage, ensuring that tasks remain available even after refreshing the page.

## Features

* Add new tasks
* Edit existing tasks
* Mark tasks as completed
* Task priority selection (Important, Medium, Low)
* Task description support
* Task statistics
  * Total Tasks
  * Pending Tasks
* Local Storage support
* Interactive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

## How It Works

1. Enter a task title.
2. Add an optional task description.
3. Select task priority.
4. Save the task.
5. Edit or update tasks when needed.
6. Mark tasks as completed.
8. Data is automatically saved in Local Storage.
